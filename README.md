# Штаб FLL: запуск в общий доступ (Vercel + Supabase)

Сайт статический, это одна страница. Данные, вход и видео хранит Supabase, а хостинг даёт Vercel.
Пользоваться сайтом могут сразу много команд. У каждой команды своё отдельное пространство и свой код приглашения.
Другие команды не видят ваши задачи, заезды, видео и Core Values: это проверяет сама база, а не страница.

## Как это работает для людей
1. Человек создаёт аккаунт (почта и пароль) и подтверждает почту по письму.
2. Дальше он либо **создаёт команду**, либо **вступает по коду** (код выглядит так: `K7QM-2XWD`).
   Ссылка-приглашение с вкладки «Команда» сама подставляет код.
3. Потом он указывает имя и роль. Создатель команды может выбрать роль «Капитан» или «Ментор».
   Остальным роли назначает капитан или ментор на вкладке «Команда».
4. Регистрация хранится в базе. Её не стирает ни очистка браузера, ни смена устройства:
   достаточно войти той же почтой. Пароль можно восстановить кнопкой «Забыли пароль?».

На вкладке «Команда» капитан или ментор может:
- сменить код (если он попал к чужим, старый код сразу перестанет работать);
- убрать человека из команды или сменить ему роль;
- **скачать копию всех данных команды** в JSON. Делайте это перед турниром и раз в неделю.

## 1. Обновить базу Supabase
> Если сайт уже работал, старые данные не потеряются. Все задачи, заезды, видео и регистрации
> переедут в команду **PEAK**, а все, кто был зарегистрирован, останутся в ней со своими ролями.

1. **Сначала сделайте копию:** Supabase → Table Editor → таблица `kv` → Export → CSV.
2. Supabase → SQL Editor → New query → вставьте весь `schema.sql` → **Run**. Должно быть «Success».
3. Внизу результата будет таблица с **кодом приглашения** команды PEAK. Сохраните его и
   отправьте в чат команды: он нужен тем, кто ещё не регистрировался.
   Узнать код позже можно на вкладке «Команда» или запросом `select name, code from teams;`.

Файл можно запускать повторно, он ничего не дублирует.
Для нового проекта шаги те же: создайте проект (регион поближе, например Frankfurt) и выполните `schema.sql`.

## 2. Настроить вход (обязательно для общего доступа)
Supabase → **Authentication**:
- **Sign In / Providers → Email:** включите **Confirm email**. Без этого любой может
  зарегистрироваться на чужую почту. Минимальную длину пароля поставьте 8.
- **Emails → SMTP Settings:** подключите свою почту. Встроенная почта Supabase отправляет всего
  несколько писем в час, при большом числе людей письма просто перестанут приходить.
  Подойдёт бесплатный тариф [Resend](https://resend.com) (3000 писем в месяц) или Brevo.
  Для Resend: Host `smtp.resend.com`, Port `465`, User `resend`, Password — API-ключ, Sender — адрес на вашем домене.
- **Emails → Templates:** переведите письма «Confirm signup» и «Reset password» на русский.
- **URL Configuration:**
  - **Site URL:** адрес сайта, например `https://shtab-fll.vercel.app`;
  - **Redirect URLs:** тот же адрес и `https://*-ваш-логин.vercel.app/**` для тестовых версий.
- **Rate Limits:** оставьте значения по умолчанию, они защищают от перебора паролей.
- По желанию: **Providers → Google** и в `config.js` поставить `GOOGLE_LOGIN: true`.

## 3. Выложить на Vercel
1. Загрузите папку в репозиторий на GitHub (файлы в корне: `index.html`, `config.js`, `vercel.json`).
2. vercel.com → Add New → Project → выберите репозиторий → Framework Preset: **Other** → Deploy.
3. Свой домен: Project → Settings → Domains. Потом впишите его в Site URL в Supabase (шаг 2).

`vercel.json` уже содержит защитные заголовки и кеширование фото.
Ключ в `config.js` (publishable/anon) публичный по замыслу: данные защищают правила в `schema.sql`.
**Никогда** не кладите в `config.js` ключ `service_role` / secret.

## 4. Лимиты бесплатного тарифа: что важно знать
| Ресурс | Бесплатно | На сколько хватит |
|---|---|---|
| База данных | 500 МБ | тысячи команд: записи маленькие |
| Файлы (видео) | **1 ГБ на всех** | около 50 видео по 20 МБ. Это главное узкое место |
| Трафик | 5 ГБ в месяц | просмотры видео быстро его съедают |
| Активные пользователи | 50 000 в месяц | с запасом |

- Если видео станет много: попросите команды вставлять ссылки на YouTube или Google Диск
  (поле «или ссылка на видео»), либо перейдите на тариф Pro (25 $ в месяц: 100 ГБ файлов, 250 ГБ трафика).
- Бесплатный проект **засыпает**, если неделю никто не заходил. Разбудить: Supabase → Restore project.
- На бесплатном тарифе нет резервных копий, которые можно скачать. Поэтому есть кнопка
  «Скачать копию данных». На Pro Supabase каждый день делает копию сам.
- Видео лежат в публичном хранилище: файл открывается по прямой ссылке, но ссылку
  невозможно угадать, а увидеть её могут только участники команды.

## 5. Проверка перед запуском
- [ ] `schema.sql` выполнен, внизу виден код команды PEAK.
- [ ] Confirm email включён, свой SMTP подключён, письмо о регистрации приходит.
- [ ] Site URL и Redirect URLs указывают на адрес Vercel.
- [ ] Второй аккаунт в другом браузере создаёт свою команду и **не видит** данные PEAK.
- [ ] «Забыли пароль?» присылает письмо, по ссылке получается задать новый пароль.
- [ ] Капитан скачал копию данных.

## Устройство (для разработчика)
- `teams`: команды и коды; `profiles`: кто в какой команде (один человек в одной команде).
- `kv`: все данные; ключ `(team, coll, id)`. Коллекции: `members`, `tasks`, `tstatus`, `runs`, `cv`, `settings`.
- Права (RLS): читать и писать можно только в своей команде. Задачи ставит капитан или ментор.
  Удалить чужой заезд или запись Core Values может только капитан или ментор.
- Функции: `create_team`, `join_team`, `leave_team`, `team_info`, `regen_team_code`,
  `remove_member`, `claim_task` (взять задачу без гонки), `kv_list_add` / `kv_list_remove`
  (миссии и чек-лист: одновременные правки двух людей не затирают друг друга).
- Видео загружаются в бакет `videos` в папку `<team>/<user>/`. Больше 20 МБ сайт сжимает сам.
- Дать почте право выбрать роль капитана или ментора в своей команде:
  `insert into staff_emails (email, team_id) select 'почта@gmail.com', id from teams where name = 'PEAK';`
